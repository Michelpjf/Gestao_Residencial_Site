# Regras de Projeto e Comportamento dos Agentes

## Design e UI (Motion Principles)
Ao criar ou alterar interfaces de usuário neste projeto, siga estritamente as seguintes diretrizes para garantir uma experiência de uso premium:
- **Motion Principles:** Aplique transições suaves (smooth animations) de entrada, saída, carregamento e progresso em todos os elementos visuais.
- **Feedback Visual e Performance:** Sempre utilize Skeletons e Lazyloading (carregamento sob demanda) para componentes e listas que dependem de dados do banco.
- O objetivo é manter uma experiência de usuário (UX) fluida e altamente profissional, evitando telas estáticas durante atrasos de rede.
