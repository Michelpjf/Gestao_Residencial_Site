# Bueno Residence - Painel de Gestão

Sistema web de gestão de condomínios residenciais, desenvolvido para a **Bueno Residence**.

## Funcionalidades
- Login com controle de perfis (Admin, Gerente, Gestor)
- Dashboard com indicadores de ocupação e financeiros
- Gestão de prédios com subdivisões personalizadas e numeração sequencial
- Mapeamento visual de unidades com grid interativo
- Controle de contratos integrado às unidades
- Log de auditoria de ações

## Como usar
Abra o terminal na pasta do projeto e execute:
```
py -m http.server 52345
```
Acesse: http://localhost:52345/index.html

## Arquivos
- `index.html` — Estrutura e telas
- `styles.css` — Design e estilos
- `app.js` — Lógica do sistema
